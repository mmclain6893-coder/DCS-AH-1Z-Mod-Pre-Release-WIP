# DCS AH-1Z Mod Pre-Release WIP

Work-in-progress DCS AH-1Z mod package.

## Install

Copy the `AH-1Z` folder into:

`Saved Games\DCS.openbeta\Mods\aircraft\AH-1Z`

This repository uses Git LFS for large model, texture, and binary files. Clone with Git LFS enabled:

```powershell
git lfs install
git clone https://github.com/mmclain6893-coder/DCS-AH-1Z-Mod-Pre-Release-WIP.git
```

## Status

Pre-release WIP. Expect active development, rough edges, and frequent changes.
